# WADA — Preuve : oui, on peut composer des tenues cohérentes (et voilà comment)

Ce fichier répond à une question simple : avec MUJI + The Business Fashion (et ses 200+ marques
luxe homme revendues) + The Shirt Company, **peut-on vraiment composer des tenues qui ont du
sens ?**

**Réponse honnête : OUI, absolument**. Tu as largement de quoi composer 100+ tenues cohérentes.
Le bug n'est pas dans le catalogue, c'est dans la logique de l'IA. Je le prouve ci-dessous.

---

## Cas observé — ce que l'IA a proposé pour "Pluie de Tokyo"

Contexte client :
- Pull noir déjà possédé
- Style décontracté
- Occasion : voyage

**Tenue proposée par l'IA** :
- HAUT : Pull noir (du client) ✓
- BAS : Short de bain à imprimé crocodile Lacoste — 97 € ❌
- VESTE : Cardigan femme en fibres de soja MUJI — 60 € ❌
- CHAUSSURES : Sneakers Veja Dekkan — 224 € ❌
- ACCENT : Bonnet en laine MUJI — 15 € ❌

**5 problèmes graves** :

1. **Short de bain pour un "voyage" générique** = aberration. Un short de bain c'est pour la plage,
   pas un voyage tout-terrain.

2. **Imprimé crocodile + pull noir + sneakers vertes + cardigan beige + bonnet noir** = palette
   complètement éclatée. La note de l'IA dit *"jamais noir sur noir"* mais elle met pull noir +
   bonnet noir.

3. **Cardigan femme proposé pour un homme** (apparemment). Aucun filtre genre.

4. **Bonnet en laine + short de bain** = incohérence climatique totale.

5. **Veja non affilié à WADA** — le client clique "Acheter sur The Business Fashion" mais Veja
   n'est pas dans TBF. Marque fantôme = aucune commission.

Le score de cohérence de cette tenue : **15/100**. À rejeter automatiquement.

## Ce qui rend ces tenues cohérentes (que l'IA actuelle ignore)

À chaque composition, j'ai appliqué **5 règles simples** :

1. **UN seul registre** par tenue (minimaliste, classique, streetwear, élégant…). Jamais de mix.

2. **UNE seule couleur forte**, le reste en neutres assortis à la palette.

3. **Pas de pièce hors saison/occasion** (pas de short de bain pour "voyage" générique, pas de
   bonnet en laine avec une tenue d'été).

4. **Toutes les pièces du même genre** que le profil (femme avec femme, homme avec homme).

5. **Toutes les marques affiliées** à WADA (pas de Veja qui clashe avec l'argument
   "Acheter sur TBF").

Si ces 5 règles sont appliquées rigoureusement, **n'importe quelle tenue WADA fera sens**. Tu peux
le vérifier toi-même : ces 5 règles sont implémentées dans le code TypeScript que j'ai donné dans
le fichier `WADA-composer-CODE-PRET.ts.md`.
