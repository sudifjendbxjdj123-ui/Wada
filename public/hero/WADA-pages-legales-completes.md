# 📄 5. Politique de cookies

À publier sur `wada.style/cookies`.

## Qu'est-ce qu'un cookie ?

Un cookie est un petit fichier déposé sur votre appareil lors de votre visite. Il permet au site
de vous reconnaître lors de visites ultérieures.

## Cookies utilisés par WADA

### Cookies strictement nécessaires (non désactivables)
- `wada_session` : maintient votre session de navigation
- `wada_consent` : mémorise vos choix de cookies

### Cookies de mesure d'audience (optionnels — Vercel Analytics ou Plausible)
- Statistiques anonymisées de fréquentation
- Aucun cookie publicitaire
- Aucun tracking croisé entre sites

### Cookies tiers
- **Stripe** : nécessaires pour le paiement (uniquement sur la page checkout)
- **Awin** : tracking d'affiliation (cookie posé par Awin chez les marchands, pas chez nous)

## Gestion de vos préférences

À votre première visite, un bandeau vous demande votre consentement pour les cookies optionnels.
Vous pouvez modifier vos choix à tout moment depuis `wada.style/cookies` ou via le footer.

## Durée de conservation

- Cookies de session : supprimés à la fermeture du navigateur
- Cookies de mémorisation : 13 mois maximum

# 📄 7. Bandeau cookies (composant)

À implémenter au premier accès. Conforme RGPD.

```tsx
// CookieBanner.tsx (Next.js)
"use client";
import { useState, useEffect } from 'react';

export default function CookieBanner() {
  const [show, setShow] = useState(false);

  useEffect(() => {
    if (!localStorage.getItem('wada_consent')) setShow(true);
  }, []);

  function accept() {
    localStorage.setItem('wada_consent', JSON.stringify({
      necessary: true,
      analytics: true,
      timestamp: Date.now()
    }));
    setShow(false);
    // Déclencher Vercel Analytics ou Plausible
  }

  function decline() {
    localStorage.setItem('wada_consent', JSON.stringify({
      necessary: true,
      analytics: false,
      timestamp: Date.now()
    }));
    setShow(false);
  }

  if (!show) return null;

  return (
    <div className="cookie-banner">
      <div className="cookie-content">
        <h4>Cookies</h4>
        <p>
          WADA utilise des cookies nécessaires au fonctionnement du site.
          Avec votre accord, nous utilisons aussi un outil d'audience anonyme
          pour améliorer le service. Aucune pub, aucun tracking croisé.
          <a href="/cookies">En savoir plus</a>
        </p>
      </div>
      <div className="cookie-actions">
        <button onClick={decline}>Refuser les analytics</button>
        <button onClick={accept} className="primary">Accepter</button>
      </div>
    </div>
  );
}
```

CSS minimaliste, en bas d'écran, fond cream, bouton bordeaux pour Accepter.
